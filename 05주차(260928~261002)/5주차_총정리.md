# Part A. 시계열(RNN)과 모델 구조

## 1. 시계열 자르기 — split_x 함수와 배열 슬라이싱

시계열은 **`split_x`** 함수로 "연속된 size개씩" 잘라 window로 만든다. 이 함수만 이해하면 어떤 시계열이든 자를 수 있다.
```python
def split_x(dataset, size):
    aaa = []
    for i in range(len(dataset) - size + 1):   # 창문이 놓일 시작 위치 개수
        subset = dataset[i : (i+size)]          # i번째부터 size개
        aaa.append(subset)
    return np.array(aaa)
```
- **`range(len-size+1)`**: 크기 size 창문이 데이터를 안 벗어나는 시작 위치 수 = window 개수.
- 자른 결과에서 x·y를 **슬라이싱**으로 나눈다:

| 표기 | 의미 |
|---|---|
| `:` | 그 축 전부 |
| `-1` | 그 축의 마지막 하나 (정수라 축이 사라짐) |
| `:-1` | 처음부터 마지막 직전까지 (범위라 축이 남음) |

```python
x = bbb[:, :-1]     # 각 window의 앞부분(입력)
y = bbb[:, -1]      # 각 window의 마지막(정답)
```
- **정수를 쓴 축은 사라지고, 범위(`:`,`:-1`)를 쓴 축은 남는다**. 3차원이면 `bbb[:, -1, 1]`처럼 축마다 지정(축0=window, 축1=타임스텝, 축2=피처).
- **피처 인덱스는 0부터**: `bbb[..., 1]`은 "1번째 피처"=두 번째 열. (`index_col=0`으로 첫 컬럼이 인덱스로 빠지면 뒤 컬럼이 한 칸씩 당겨짐 — jena에서 T가 1번인 이유.)

## 2. RNN 계열 심화 — 게이트·다층·양방향

### 층별 파라미터 (게이트 수가 곧 배수)
기본 RNN 한 묶음 = `units × (feature + units + 1)`. 여기에 게이트 수를 곱한다.

| 층 | 게이트 | 파라미터 (units=10, feature=1 예) |
|---|---|---|
| SimpleRNN | 없음 | 120 (×1) |
| GRU | 3개 | 390 (×3 + bias 한 벌 더) |
| LSTM | 4개 | 480 (×4) |

- SimpleRNN은 앞을 잊는 문제(장기의존성)가 있고, LSTM이 이를 개선(가장 강력), GRU는 LSTM을 간소화(게이트 하나 적어 파라미터↓). GRU가 정확히 390인 건 Keras 기본 구현이 bias를 한 벌 더 두기 때문(구현 세부).

### RNN 다층 — return_sequences
- RNN은 기본적으로 **마지막 타임스텝만** 내보내 2D로 나온다. 다음 RNN 층은 3D가 필요하므로 그냥 못 쌓는다.
- **`return_sequences=True`**: 모든 타임스텝을 내보내 **3D 유지** → 다음 RNN에 연결 가능.
- **규칙**: 중간 RNN 층은 전부 `True`, **마지막 RNN만 빼서(False)** 2D로 Dense에 연결.
- 다층이 성능을 꼭 올리진 않는다(실습에서 단층보다 낮게 나오기도).

### Bidirectional (양방향)
- 시퀀스를 **앞→뒤 + 뒤→앞** 양방향으로 읽어 양쪽 맥락을 본다.
- **모델이 아니라 "래퍼(wrapper)"**: 기존 RNN을 감싼다. `Bidirectional(LSTM(64), input_shape=(3,1))` (괄호 주의).
- 파라미터 2배(정방향+역방향). **항상 좋아지진 않음**(실습에서 79.85→73.12로 하락한 사례).

## 3. 모델별 차원 구조 총정리 (핵심)

| 구분 | DNN | CNN | RNN | Embedding |
|---|---|---|---|---|
| **x(입력) 차원** | 2 | 4 | 3 | 2 |
| **input_shape 숫자 개수** | 1 | 3 | 2 | 1 |
| **output 차원** | 2 | 4 | 2 | 3 |
| **return_sequences** | — | — | 3 | — |
| **Flatten 후** | 2 | 2 | 2 | 2 |

- 입력: DNN `(N,피처)` / CNN `(N,H,W,C)` / RNN `(N,타임스텝,피처)` / Embedding `(N,길이)`.
- input_shape엔 **맨 앞 샘플 수(N)를 항상 뺀다**.
- **Embedding은 2D→3D**(각 단어가 벡터가 됨), RNN 출력은 2D(단, return_sequences=True면 3D), CNN 출력은 4D.
- 연결 규칙: **Embedding(2D→3D)→RNN(3D→2D)→Dense** 자연스러움 / **CNN(4D)→Flatten(2D)→Dense** / **CNN→RNN은 Reshape(4D→3D) 필요**.

## 4. 모델 재구성 (→LSTM)과 Reshape 층

### 데이터를 LSTM 형태로 (reshape 순서)
- RNN은 3D `(N,타임스텝,피처)`가 필요. 표·이미지를 reshape해 넣는다.
```python
x = x.reshape(-1, 8, 1)             # 표 (N,8)→(N,8,1): 피처를 타임스텝으로
x_train = x_train.reshape(-1, 784, 1)   # 이미지 (N,28,28)→(N,784,1)
```
- **스케일러는 2D만 받는다**: 순서는 **split → 스케일링(2D) → reshape(3D)**. 3D를 먼저 만들면 스케일러가 거부(dim 3 에러).
- **증폭(datagen.flow)은 4D 이미지 필요**: 증폭·합치기를 이미지(4D)로 끝낸 뒤 맨 마지막에 `(N,784,1)`로 변환.

### 모델 안에서 차원 바꾸기 — Reshape 층
- `x.reshape`는 데이터 단계, **`Reshape` 층**은 모델 안 층 사이에서 차원 변환.
- **총 원소 수 보존** 필수. `target_shape`엔 배치(N) 제외, **`-1` 넣으면 차원이 더 생겨 에러**.
- **CNN→LSTM 연결**: `Reshape(H×W, 채널)`로 공간을 타임스텝, 채널(마지막 Conv 필터 수)을 피처로. 예: `(23,23,32)→(529,32)`.

### 결과 — "데이터에 맞는 모델" (실측, 정직하게)
| 데이터 | LSTM 결과 |
|---|---|
| digits(8×8) | acc 약 0.97 |
| cancer(피처30) | acc 약 0.98 |
| **mnist(28×28→784스텝)** | **acc 약 0.11 (사실상 랜덤, 실패)** |
| fashion | acc 약 0.75 |
| cifar10 | acc 약 0.66 |
- **큰 이미지일수록 LSTM 성능 급락** → "이미지=CNN, 시계열=RNN"을 수치로 확인. 784스텝 LSTM은 느리기도 하다.

## 5. jena 시계열 회귀 실습

실제 기후 데이터로 특정 컬럼을 예측. **split_x로 자르고 → x/y 분리(예측 구간 제외) → 3D 스케일링 → 예측**.
```python
x = bbb[:-144, :, :-1]       # 마지막 144 window는 학습 제외(과적합 방지)
y = bbb[:-144, -1, -1]       # 마지막 timestep의 타깃 컬럼
# 예측 구간 = bbb[-144:] (학습에서 뺀 바로 그 구간)
```
- **타깃 교체(wd→T)**: 중간 컬럼은 `np.delete(..., 1, axis=2)`로 x에서 빼고 `y=bbb[...,1]`로.
- **결과 (정직하게)**:
  - **wd(풍향)**: R² 약 **-0.13** (평균 찍기보다 못함). 원인 추정 — wd는 각도(0~360)라 359°≈1°의 불연속 때문에 일반 회귀가 불리(*추측*).
  - **T(온도)**: R² 약 **0.9987**. 온도는 연속·완만해 예측이 쉬움.
- 핵심은 성능보다 **대용량 시계열 파이프라인 완성**(자르기·예측 구간 구성·3D↔2D 스케일링).

# Part B. 자연어 처리와 RAG

## 6. 텍스트 수치화 파이프라인 — 토큰화 → 원핫 → 패딩

### 토큰화 (Tokenizer)
```python
token = Tokenizer()
token.fit_on_texts(docs)         # 단어장 구축(많이 나온 단어=작은 번호)
x = token.texts_to_sequences(docs)   # 텍스트 → 번호 시퀀스
```
- **번호는 ID일 뿐 크기 의미 없음**('마구'=1이 2개라고 '진짜'=2 아님). 문장부호는 기본 `filters`가 자동 제거.

### 원핫 (번호 → 위치)
번호의 가짜 순서를 없애려 "값→위치"로 바꾼다. 세 방법, 입력 요구가 다름:

| 방법 | 입력 | 비고 |
|---|---|---|
| `to_categorical` | 리스트/배열 OK | 2D→3D 한 번에 |
| `get_dummies` | 1차원 | 바로 DataFrame |
| `OneHotEncoder` | 2차원 `(N,1)` | `reshape(-1,1)` 필요 |

### 패딩 (길이 맞추기)
```python
pad_sequences(x, padding='pre', maxlen=5, truncating='post')
```
- 문장마다 길이가 달라서 통일. **`pre`(앞 채움) 권장**(뒤 채우면 맥락 흐려짐). maxlen 초과 시 truncating으로 자름.

---

## 7. 임베딩 (Embedding)

원핫의 한계(**단어 많아질수록 0투성이·연산 낭비, 의미도 못 담음**)를 푸는 방법.
```python
model.add(Embedding(input_dim=단어장크기, output_dim=벡터차원, input_length=문장길이))
```
- **단어 번호 → 학습되는 밀집 벡터**로 바꾸는 룩업 테이블. "비슷한 단어는 비슷한 벡터"가 되도록 학습.
- **파라미터 = input_dim × output_dim** (bias 없음, input_length는 무관).
- **input_dim은 최대 토큰 번호+1 이상**이어야 안전(그 수보다 큰 토큰은 범위 밖).
- Embedding(2D→3D)이라 **바로 RNN(3D)에 연결** 가능.

## 8. 텍스트 분류 실습 (reuters / imdb) + sparse

| | reuters | imdb |
|---|---|---|
| 클래스 | 46개(다중) | 2개(이진) |
| 데이터 분리 | `test_split=0.2` 사용 | 이미 분리됨(옵션 없음) |
| y 원핫 | 필요 | 불필요(0/1) |
| 출력층 | `Dense(46, softmax)` | `Dense(1, sigmoid)` |
| loss | categorical_crossentropy | binary_crossentropy |
| 결과(실측) | acc 약 0.75 | LSTM 0.85 / GRU 0.86 |

### sparse_categorical_crossentropy
- 다중분류에서 **y를 원핫하지 않고 정수 그대로** 쓰게 해주는 loss(내부 자동 원핫).
- **주의**: `y_predict`는 argmax 필요(확률→라벨), **`y_test`는 이미 정수라 argmax 삭제**(원핫 버전 코드 복붙 시 흔한 에러).

## 9. RAG 입문 — LangChain

### API 키 관리 (노출 금지가 핵심)
하드코딩(❌) → `os.environ`(❌) → 시스템 환경변수 → **`.env` + `load_dotenv()`(✅ 실무)** → `.gitignore`로 `.env` 제외.
```python
from dotenv import load_dotenv
load_dotenv()
api_key = os.environ["MONOROUTER_API_KEY"].strip()
```
> ⚠️ 키를 코드(.py)에 박아두면 `.gitignore`로 못 막아 Public 레포에 노출됨. 실습 후 하드코딩 키는 제거할 것.

### LCEL 체인 & 출력 파서
```python
chain = prompt | model | output_parser   # 파이프로 단계 연결
chain.invoke({"topic": "..."})            # 실행
```
- **`PromptTemplate`**: `{변수}` 빈칸 템플릿. **LCEL**: `|`로 prompt→model→output 연결. **`StrOutputParser`**: 응답을 바로 문자열로(`.content` 불필요).

### 임베딩 (keras vs RAG)
- keras `Embedding`: "단어 번호→학습 벡터"(모델이 학습).
- RAG `OpenAIEmbeddings.embed_query(문장)`: **이미 학습된 모델로 문장을 의미 벡터로** 변환. `text-embedding-3-small`=1536차원, `-3-large`=3072차원, `dimensions`로 축소 가능.
- 이 문장 벡터 비교(유사도)가 RAG 문서 검색의 기반이 된다.

## 10. 키워드 총괄

| 키워드 | 한 줄 정의 |
|---|---|
| `split_x` | 시계열을 size개씩 잘라 window 생성 |
| 슬라이싱 `:` `-1` `:-1` | 전부 / 마지막 하나(축소멸) / 마지막 직전까지(축유지) |
| SimpleRNN·LSTM·GRU | 게이트 0·4·3개 → 파라미터 ×1·×4·×3 |
| `return_sequences=True` | 모든 타임스텝 출력(3D 유지) → RNN 다층용 |
| Bidirectional | RNN을 양방향으로 감싸는 래퍼(파라미터 2배) |
| 차원 규칙 | DNN 2D·RNN 3D·CNN 4D·Embedding 2D→3D |
| `Reshape` 층 | 모델 안 차원 변환(총 원소 수 보존, -1 금지) |
| Tokenizer | 텍스트→단어장→번호 시퀀스 |
| 원핫 3종 | to_categorical/get_dummies/OneHotEncoder(입력요구 다름) |
| `pad_sequences` | 길이 통일(pre·maxlen·truncating) |
| Embedding | 번호→학습 밀집벡터, 파라미터=input_dim×output_dim |
| sparse_categorical_crossentropy | 정수 y로 다중분류(원핫 자동, y_test argmax 불필요) |
| `.env`/load_dotenv | API 키를 코드와 분리, .gitignore로 제외 |
| LCEL | `prompt \| model \| parser` 파이프 체인 |
| OpenAIEmbeddings | 문장→의미 벡터(small 1536/large 3072) |

## 11. 이번주 한 줄 요약

> **시계열**은 `split_x`로 자르고 슬라이싱(`:`,`-1`,`:-1`)으로 x·y를 나눈다. **RNN 계열**은 게이트 수로 파라미터가 갈리고(SimpleRNN·GRU·LSTM = ×1·×3·×4), 다층은 `return_sequences=True`로 3D를 유지하며, `Bidirectional`은 양방향 래퍼다(둘 다 성능 보장은 없음).
> **차원 규칙**(DNN 2D·CNN 4D·RNN 3D·Embedding 2D→3D)이 모델 연결·변환의 기준이고, 데이터를 다른 모델로 바꿀 땐 **스케일링(2D)→reshape(3D)** 순서와 **`Reshape` 층(총 원소 보존)** 을 쓴다. 큰 이미지는 LSTM에서 성능이 급락(mnist≈0.11)해 "이미지=CNN"을 확인시킨다. jena는 타깃이 각도(wd)면 R²가 음수, 온도(T)면 0.999로, **타깃 성질이 성능을 좌우**한다.
> **자연어**는 토큰화→(원핫)→패딩→**임베딩**으로 수치화하며, 원핫의 희소성 한계 때문에 임베딩을 쓴다. 텍스트 분류는 클래스 수로 갈리고(reuters 46/softmax, imdb 2/sigmoid), `sparse_categorical_crossentropy`로 y 원핫을 생략할 수 있다.
> **RAG 입문**: LangChain으로 LLM을 호출하며 **API 키는 `.env`로 분리**, **LCEL(`prompt | model | parser`)** 로 체인을 잇고, **임베딩으로 문장을 의미 벡터화**(RAG 검색의 기반)한다.
