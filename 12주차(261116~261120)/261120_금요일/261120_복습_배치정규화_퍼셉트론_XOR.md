# A. 배치 정규화(BatchNormalization)

## 1. 배치 정규화란

지금까지 **입력 데이터**를 0~1로 스케일링(`x/255.`)해 넣었다. 그런데 층이 깊어지면 **중간 층의 출력값 분포**도 학습이 진행되며 들쭉날쭉해진다(앞 층의 가중치가 바뀌면 다음 층이 받는 값의 분포가 계속 변함 — 이를 **내부 공변량 변화**라 한다). 이러면 학습이 불안정하고 느려진다.

**배치 정규화는 각 층의 출력을 배치(batch) 단위로 "평균 0, 분산 1"에 가깝게 정규화**해 이 문제를 줄인다. 입력뿐 아니라 **신경망 중간 층에서도** 값을 고르게 맞춰주는 것이다.

- **효과**: ① 학습이 **안정되고 빨라진다**(더 큰 학습률도 견딤), ② **기울기 소실 완화**, ③ 약한 **규제(regularization)** 효과(과적합을 다소 줄여, Dropout 의존을 낮추기도 함).
- **쓰는 법**: `BatchNormalization()` 레이어를 Conv/Dense 층 **뒤에** 추가한다. 학습할 파라미터(스케일 γ·이동 β)를 가져, 정규화 후 적절히 되돌리는 것까지 학습한다.

## 2. keras81_1 — BN을 활성화 뒤에 넣기

MNIST 손글씨 분류 CNN(Conv 여러 층 + Dense)에 `BatchNormalization()`을 한 군데 넣은 형태다.

```python
from tensorflow.keras.layers import Conv2D, Dense, Dropout, Flatten, BatchNormalization

model.add(Conv2D(32, (2,2), activation='relu'))   # 활성화(relu)까지 적용된 출력
model.add(BatchNormalization())                   # 그 출력을 정규화
```

- 데이터 전처리는 이미지라 **`x/255.`** 로 0~1 스케일링(이미 최대 255 고정이라 MinMax 대신)하고, CNN 입력을 위해 `reshape(-1, 28, 28, 1)`로 4차원(채널 1)으로 만든다. y는 `OneHotEncoder`로 10개 클래스 원-핫 인코딩한다.
- 여기서는 `Conv2D(..., activation='relu')`로 **활성화를 적용한 뒤** `BatchNormalization()`을 뒀다. 이것도 동작하지만, 더 일반적인 "정석" 배치는 다음 파일이다.

## 3. keras81_2 — BN을 활성화 앞에 넣기(정석 패턴)

배치 정규화를 **활성화 함수 앞에** 두는, 원 논문에 가까운 패턴이다. Conv에서는 활성화를 끄고(`activation=None`), **BN → Activation** 순서로 분리한다.

```python
from tensorflow.keras.layers import Activation, BatchNormalization

model.add(Conv2D(32, (3,3), activation=None))   # ① 활성화를 끄고 선형 출력만
model.add(BatchNormalization())                 # ② 먼저 정규화
model.add(Activation('relu'))                   # ③ 그 다음 활성화
```

- **핵심 순서**: `Conv(activation=None)` → `BatchNormalization()` → `Activation('relu')`. 활성화 함수에 넣기 **전에** 값을 먼저 정규화해, relu가 안정된 분포의 입력을 받도록 한다. 이것이 BN을 쓰는 가장 흔한 방식이다.
- **`activation=None`**: Conv 층에서 활성화를 적용하지 않고 **선형 결과만** 내보낸다. 그래야 그 뒤에서 BN → Activation을 따로 끼울 수 있다.
- 이 구성으로 MNIST에서 **정확도 약 0.988**(주석 실측). 배치 정규화를 넣으면 더 적은 에폭으로도 안정적으로 높은 정확도에 도달한다.

# B. 퍼셉트론과 XOR 문제

## 4. 퍼셉트론과 논리 게이트

**퍼셉트론(Perceptron)은 가장 단순한 신경망 단위**로, 입력에 가중치를 곱해 더한 값으로 0/1을 판정하는 **선형 분류기**다. 이것으로 **논리 게이트(AND·OR·XOR)** 를 학습시켜 본다. 입력은 `(0,0),(0,1),(1,0),(1,1)` 네 경우이고, 게이트마다 정답(y)이 다르다.

- **선형 분리(linearly separable)**: 2차원 평면에 점을 찍었을 때, **직선 하나로 0인 점들과 1인 점들을 가를 수 있는가**가 핵심이다. 퍼셉트론·`LinearSVC` 같은 선형 모델은 **직선 하나로 가를 수 있는 문제만** 풀 수 있다.

```python
from sklearn.linear_model import Perceptron
from sklearn.svm import LinearSVC    # 둘 다 선형 분류기
x_data = [[0,0], [0,1], [1,0], [1,1]]
model = LinearSVC()
model.fit(x_data, y_data)
```

## 5. m11_1·m11_2 — AND·OR (선형 분리 가능)

```python
# AND: 둘 다 1일 때만 1
y_data = [0, 0, 0, 1]   # m11_1
# OR: 하나라도 1이면 1
y_data = [0, 1, 1, 1]   # m11_2
```

- **AND**(`(1,1)`만 1)와 **OR**(`(0,0)`만 0)은 평면에 그려 보면 **직선 하나로 1과 0을 깔끔히 가를 수 있다.** 그래서 선형 모델(`LinearSVC`/`Perceptron`)로도 **정확도 1.0**이 나온다.

```
 AND              OR
 1│ 0   1         1│ 1   1
  │     ╱직선      │ ╱직선
 0│ 0  ╱0         0│0   1
  └───────         └───────
   0   1            0   1
```

## 6. m11_3 — XOR, 단층 선형 모델의 한계

```python
# XOR: 서로 다를 때만 1
y_data = [0, 1, 1, 0]   # m11_3
model = LinearSVC()     # 선형 모델로는…
```

- **XOR**은 `(0,1)`·`(1,0)`이 1이고 `(0,0)`·`(1,1)`이 0이다. 평면에 그리면 **같은 클래스가 대각선으로 마주 보고** 있어, **직선 하나로는 0과 1을 가를 수 없다**(선형 분리 불가능).
- 그래서 `LinearSVC`(단층 선형 모델)로는 네 개를 다 맞히지 못해 **정확도가 1.0에 못 미친다.** 이것이 **단층 퍼셉트론의 결정적 한계**다.

```
 XOR  ← 직선 하나로 못 가름
 1│ 1   0
  │   ✕
 0│ 0   1
  └───────
   0   1
```

## 7. m11_4 — 단층 신경망도 XOR 실패

선형 모델 대신 **신경망(Keras)** 을 써도, **층이 하나(은닉층 없음)** 면 결국 선형이라 XOR을 못 푼다.

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential()
model.add(Dense(1, input_dim=2, activation='sigmoid'))   # 출력층 하나뿐 = 단층

model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['acc'])
model.fit(x_data, y_data, epochs=1000)
```

- 입력에서 바로 출력으로 가는 **단층 구조**(은닉층 없음)다. 활성화가 sigmoid라도 층이 하나면 **직선 하나로 가르는 것과 다름없어**, **epochs를 1000이나 줘도 XOR 정확도가 오르지 않는다**(보통 0.5 근처). 신경망이라고 저절로 풀리는 게 아니라, **구조(깊이)가 문제**임을 보여준다.

## 8. m11_5 — 은닉층을 더해 XOR 해결

입력과 출력 사이에 **은닉층(hidden layer)** 을 하나 넣으면 XOR이 풀린다.

```python
model = Sequential()
model.add(Dense(10, input_dim=2))     # ★ 은닉층 (노드 10개) 추가
model.add(Dense(1, activation='sigmoid'))  # 출력층

model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['acc'])
model.fit(x_data, y_data, epochs=100)   # 100에폭만으로도 풀림
```

- **은닉층을 두면 입력 공간을 여러 번 변형**해, 직선 하나로는 못 가르던 XOR을 **가를 수 있는 형태로 바꾼다.** 그래서 단층(m11_4)에서 1000에폭도 안 되던 것이, **은닉층을 더하자 100에폭만으로 정확도 1.0**에 도달한다.
- 이것이 **다층 퍼셉트론(MLP, Multi-Layer Perceptron)** 이다. "층을 여럿 쌓고(깊이) 비선형을 넣어야 복잡한 문제를 푼다"는 딥러닝의 기본 원리를, 가장 작은 예(XOR)로 확인하는 것이다.

## 9. 역사적 맥락 — XOR 문제와 딥러닝

> **(보충)** 이 실습은 신경망 역사에서 유명한 사건을 재현한 것이다. 1958년 퍼셉트론이 발표돼 기대를 모았지만, 1969년 민스키와 페퍼트가 **"단층 퍼셉트론은 XOR조차 풀지 못한다"** 는 것을 수학적으로 보였다. 이 한계가 신경망 연구의 침체기("AI 겨울")를 불렀다. 이후 **은닉층을 쌓은 다층 퍼셉트론과 역전파 학습**이 XOR 같은 비선형 문제를 풀 수 있음이 밝혀지며 신경망이 다시 부활했고, 오늘날 딥러닝으로 이어졌다. m11_3→m11_4→m11_5의 흐름이 바로 이 "한계 → 해결"의 축소판이다.

## 한 줄 요약

> **배치 정규화(BatchNormalization)** 는 입력뿐 아니라 **신경망 중간 층의 출력도 배치 단위로 평균0·분산1에 가깝게 정규화**해 학습을 안정·가속하고(기울기 소실 완화·약한 규제 효과), 보통 `Conv(activation=None) → BatchNormalization() → Activation('relu')` 순으로 **활성화 앞에** 넣는다(MNIST에서 acc 약 0.988). **퍼셉트론과 XOR**: 퍼셉트론·`LinearSVC` 같은 단층 선형 모델은 **직선 하나로 가를 수 있는** AND·OR은 풀지만(정확도 1.0), **선형 분리가 불가능한 XOR은 못 푼다.** 신경망이라도 **은닉층이 없으면(단층)** epochs를 아무리 늘려도 XOR을 못 풀고(m11_4), **은닉층을 하나 더하면(다층 MLP)** 비로소 풀린다(m11_5). 이는 "복잡한 문제엔 깊이(은닉층)와 비선형이 필요하다"는 딥러닝의 핵심 원리이자, 역사적 XOR 문제의 재현이다.
