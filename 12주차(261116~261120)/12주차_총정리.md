## A. 데이터 전처리 — 결측치 처리 · pandas 인덱싱 (11/16)

### A-1. 결측치(NaN) 처리 — 단순에서 정교로

비어 있는 값(결측치)을 다루는 방법은 "단순 → 정교" 순으로 쌓인다.

- **삭제** `dropna(axis=0/1)`: 결측 있는 행(0)·열(1)을 버린다.
- **채우기** `fillna`: 평균(`mean`, 이상치에 약함)·중위값(`median`)·0, 앞값(`ffill`)·뒷값(`bfill`).
- **보간** `interpolate`: 알려진 값 사이를 추정해 채운다. **중간은 선형(앞뒤 직선), 맨 끝은 앞값으로, 맨 앞은 기준이 없어 NaN으로** 남는다.

```python
data.dropna(axis=0)          # 결측 행 삭제
data['x1'].fillna(data['x1'].mean())   # 열별로 다른 전략 가능
ts.interpolate()             # 선형 보간
```

### A-2. sklearn Imputer 3종

pandas `fillna`와 비슷하지만 **`fit_transform` 규격**이라 머신러닝 파이프라인에 그대로 끼운다.

| Imputer | 채우는 방식 | 특징 |
|---|---|---|
| **SimpleImputer** | 열의 통계값(mean·median·most_frequent·constant) | 가장 단순·빠름, 관계 무시 |
| **KNNImputer** | 가까운 이웃 K개 샘플의 값 | 행 간 유사성 반영, 스케일 민감 |
| **IterativeImputer** | 다른 열로 결측 열을 예측하는 모델을 반복 | 가장 정교, 무거움(실험적 기능) |

- `IterativeImputer`는 `estimator`에 XGBoost 등을 넣어, "다른 열로 결측 열을 회귀 예측 → 반복 수렴"(MICE 방식)한다. `enable_iterative_imputer`를 먼저 import해야 켜진다.

### A-3. pandas 인덱싱 — loc / iloc

```python
df['종목명']['045']      # df[...]는 '열 먼저'(열→행) 순서
df.loc['045', '종가']    # loc : 라벨(이름) 기준
df.iloc[3, 2]            # iloc : 정수 위치 기준 ("int loc"로 암기)
df.iloc[3:5, 1]          # 범위는 쉼표 안에 (끝 번호 미포함)
```

- **`df[...]`는 열이 먼저**(열행). **`loc`=라벨 / `iloc`=정수 위치**이고, `iloc[행,열]`은 둘 다 정수·`loc[행,열]`은 둘 다 라벨로 쓴다. 슬라이싱 범위(`iloc[3:5,1]`)는 끝 번호를 포함하지 않는다.

## B. LLM 도구 활용 기초 — Tool Calling · 데코레이터 (11/18)

### B-1. Tool Calling — LLM이 함수를 쓰게 하기

LLM이 약한 일(정확한 계산 등)을 **미리 만든 함수(도구)에 맡기는** 방식. 핵심은 **① LLM은 "무엇을 어떻게 부를지" 결정만, ② 실제 실행은 코드가** 한다는 2단계다.

```python
from langchain_core.tools import tool

@tool
def add(aaa:int, bbb:int) -> int:
    """두 정수를 더합니다."""        # ← 독스트링을 LLM이 읽고 언제 쓸지 판단
    return aaa + bbb

llm_with_tools = llm.bind_tools([add])              # 도구 등록
response = llm_with_tools.invoke("233123과 1232451을 더해줘")
response.tool_calls        # [{'name':'add','args':{...},'id':...}] ← 호출 '결정'
add.invoke(call['args'])   # 실제 실행은 코드가
```

- **`@tool`**: 함수를 도구로 변환(이름→name, 독스트링→description, 타입힌트→args 스키마).
- **`bind_tools`** 로 등록하면 LLM이 `tool_calls`(name·args·id)로 **호출 계획**을 세우고, **실제 실행은 `도구.invoke()`** 로 코드가 한다.
- 도구가 여럿이면 **`tool_map = {tool.name: tool}`** 으로 이름→도구를 매핑해, LLM이 고른 `call['name']`으로 찾아 실행한다. 이것이 **AI 에이전트의 기초**다.

### B-2. 파이썬 데코레이터 — `@tool`의 정체

**데코레이터는 기존 함수를 수정하지 않고 기능을 덧붙이는** 문법이다.

```python
def deco(func):
    def wrapper():
        print("실행 전"); func(); print("실행 후")   # 원래 함수 앞뒤에 기능 추가
    return wrapper

@deco              # hello = deco(hello) 와 같음
def hello(): print("안녕")
```

- `@deco`는 `hello = deco(hello)`와 같아, 함수가 **wrapper로 교체**되며 앞뒤에 기능이 붙는다. 실행시간 측정·로그 같은 **공통 기능 재사용**에 쓴다. 오늘 배운 **`@tool`도 이 데코레이터** — 함수를 LangChain 도구 객체로 감싸 바꾼 것이다.

## C. 딥러닝 심화 — 배치 정규화 · 퍼셉트론과 XOR (11/20)

### C-1. 배치 정규화(BatchNormalization)

입력뿐 아니라 **신경망 중간 층의 출력도 배치 단위로 "평균0·분산1"에 가깝게 정규화**해, 층이 깊어질 때 값 분포가 흔들리는 문제(내부 공변량 변화)를 줄인다. → 학습 안정·가속, 기울기 소실 완화, 약한 규제 효과.

```python
model.add(Conv2D(32, (3,3), activation=None))   # ① 활성화 끄고 선형 출력
model.add(BatchNormalization())                 # ② 먼저 정규화
model.add(Activation('relu'))                   # ③ 그 다음 활성화
```

- 정석 배치는 **`Conv(activation=None) → BatchNormalization → Activation` 순**(활성화 앞에서 정규화). MNIST에서 정확도 약 0.988.

### C-2. 퍼셉트론과 XOR — 왜 깊이가 필요한가

단층 선형 모델(Perceptron·`LinearSVC`)로 논리 게이트를 학습시켜, **선형 분리 가능성**을 확인한다.

- **AND·OR**: 직선 하나로 0/1을 가를 수 있다(선형 분리 가능) → 단층으로 정확도 1.0.
- **XOR**(`[0,1,1,0]`): 같은 클래스가 대각선으로 마주봐 **직선 하나로 못 가른다**(선형 분리 불가) → 단층은 실패.

```python
# 단층 신경망 → XOR 실패 (epochs 1000도)
model.add(Dense(1, input_dim=2, activation='sigmoid'))
# 은닉층 추가 → XOR 해결 (100 epochs로 acc 1.0)
model.add(Dense(10, input_dim=2))      # ★ 은닉층
model.add(Dense(1, activation='sigmoid'))
```

- 신경망이라도 **은닉층이 없으면(단층)** XOR을 못 풀고, **은닉층을 더한 다층(MLP)** 이라야 입력 공간을 변형해 풀 수 있다. "복잡한 문제엔 **깊이(은닉층)와 비선형**이 필요하다"는 딥러닝의 핵심 원리이자, 1969년 "단층 퍼셉트론은 XOR을 못 푼다"는 역사적 사건의 재현이다.

## 한 주 핵심 한 줄

> **데이터 전처리**: 결측치는 `dropna`(삭제)·`fillna`/`ffill`/`bfill`(채우기)·`interpolate`(보간)로, 혹은 sklearn Imputer로 **SimpleImputer(통계값)→KNNImputer(이웃)→IterativeImputer(모델 예측)** 순으로 정교하게 처리하고, pandas 인덱싱은 `df[...]`가 열 먼저이며 **loc(라벨)·iloc(정수위치)** 를 구분한다. **LLM 도구**: `@tool`로 함수를 도구화하고 `bind_tools`로 등록하면 LLM은 `tool_calls`로 **호출만 결정**하고 실행은 코드(`도구.invoke`)가 하며(여러 도구는 `tool_map`), 이 `@tool`의 바탕이 **데코레이터**(함수를 감싸 기능을 더하는 문법)다. **딥러닝**: **배치 정규화**는 중간 층 출력을 정규화해 학습을 안정·가속(`Conv(None)→BN→Activation`)하고, **퍼셉트론·XOR** 실습은 단층이 XOR(선형 분리 불가)을 못 풀고 **은닉층(다층 MLP)** 이라야 푼다는 것 — 즉 신경망에 깊이와 비선형이 필요한 이유를 보여준다.
