## 1. keras13_ddarung01 — 경로와 문자열

### 경로(path) 개념
```python
path = "./_data/ddarung/"   # 상대경로
```
- **상대경로**: 현재 실행 위치를 기준으로 한 경로. 맨 앞의 `.`(점)은 **현재 실행 위치(작업 디렉터리)** 를 가리킨다. VSCode에서 프로젝트 폴더를 열고 실행하면 그 최상위 폴더가 실행 위치가 되므로, `.`은 그 최상위를 가리키게 된다.
- **절대경로**: 드라이브부터 전체 경로를 다 적는 방식. 예: `C:/study/_data/ddarung/`. 실행 위치와 무관하게 항상 같은 곳을 가리킨다.
- 윈도우 경로의 슬래시는 `/`, `//`, `\\` 등이 모두 동작하지만, `\`는 파이썬에서 특수문자로 해석될 수 있어 **`/`로 통일**하는 것이 안전하다. 여러 방식을 섞어 쓰는 것은 권장하지 않는다.

### 문자열과 따옴표
- `" "` 안의 내용은 **문자열**이다. `' '`(작은따옴표)로 써도 동일하다.

## 2. keras13_ddarung02_submit — 제출 파일 완성

### 주석
- **`#`**: 라인(한 줄) 주석. 파이썬의 진짜 주석은 이것뿐이다.
- **`""" 내용 """`, `''' 내용 '''`**: 엄밀히는 여러 줄 **문자열**이지만, 코드에 남기는 여러 줄 메모(블록 주석)처럼 관례적으로 사용한다.

### 용어 정리 — 열의 여러 이름
**열 = 컬럼(column) = 특성 = 속성 = 피처(feature) = 어트리뷰트(attribute)** — 모두 같은 것을 가리킨다. 하나의 입력 항목을 뜻한다.

예측값도 코드마다 다른 이름으로 쓰였다: **ŷ(y hat) = result = y_predict = y_pre** — 모두 모델이 내놓은 예측값을 가리킨다.

### 결측치 처리 2 — 평균값 채우기(fillna)
전날 배운 삭제(dropna)에 이어, 두 번째 방법은 **평균값으로 채우기**다.
```python
test_csv = test_csv.fillna(test_csv.mean())   # 결측치를 각 컬럼 평균으로 채움
```
- **`fillna`**: 결측치를 지정한 값으로 채운다. `test_csv.mean()`을 넣으면 각 컬럼의 평균으로 채운다.
- **test 데이터에는 삭제(dropna)가 아니라 채우기(fillna)를 쓴다.** test는 제출을 위해 **모든 행을 예측해야** 하므로, 결측이 있다고 행을 지우면 제출해야 할 데이터가 사라진다. 그래서 삭제 대신 평균으로 채워 행 수를 유지한다. (train은 정답 학습용이라 일부 삭제해도 되지만, test는 그럴 수 없다.)

### submission 만들기 (제출 파일 생성)
```python
y_submit = model.predict(test_csv)     # test 전체를 예측
submission['count'] = y_submit         # 제출 양식의 count 컬럼에 예측값 채우기
submission.to_csv(path + "submit/" + "submit_0904_1337.csv")   # csv로 저장
```
- test_csv 전체를 예측해 예측값(y_submit)을 만든다.
- 제출 양식(submission)의 **count 컬럼에 예측값을 채운다.**
- **`to_csv`**: DataFrame을 csv 파일로 저장한다. 지정한 경로(`submit/`)에 결과 파일이 만들어진다. (해당 폴더가 없으면 미리 만들어야 저장된다.)
- 이 csv를 데이콘 대회에 제출한다.

### 하이퍼파라미터 명세서
튜닝 시도를 기록으로 남긴다. 어떤 설정에서 어떤 성능이 나왔는지 추적하기 위함이다.
```
- 1차 시도: random_state=337, train_size=0.75, epoch=50, batch_size=1 → rmse=37, r2=0.66
- 2차 시도: random_state=4007, train_size=0.7, epoch=100, batch_size=1 → rmse=35, r2=0.65
```
- 설정(random_state·train_size·epoch·batch_size)과 결과(rmse·r2)를 함께 적어, 무엇을 바꿨을 때 성능이 어떻게 변하는지 비교한다.

## 4. keras14_kaggle_bike1 — 캐글 자전거 대여 예측

### 데이터 컬럼
`datetime`을 인덱스로 쓴다(`index_col=0`). 주요 컬럼:

| 컬럼 | 의미 |
|---|---|
| season | 계절 (1 봄, 2 여름, 3 가을, 4 겨울) |
| holiday | 공휴일 여부 |
| workingday | 주말·공휴일이 아닌 근무일 여부 |
| weather | 날씨 (1 맑음 ~ 4 폭우·폭설) |
| temp | 기온(℃) |
| atemp | 체감온도(℃) |
| humidity | 습도 |
| windspeed | 풍속 |
| casual | 미등록 사용자 대여 수 |
| registered | 등록 사용자 대여 수 |
| count | 총 대여 수 (예측 대상 = y) |

- 데이터 크기: train (10886, 11), test (6493, 8), submission (6493, 1).

### 결측치 확인 — isna / isnull
```python
print(train_csv.isna().sum())     # 컬럼별 결측치 개수
print(train_csv.isnull().sum())   # isna와 동일 (isnull은 isna의 별칭)
```
- **`isna()`와 `isnull()`은 완전히 같은 함수다.** `isnull`은 `isna`의 별칭이며 동작이 동일하다. 둘 다 각 칸이 결측치인지 True/False로 표시한다.
- 여기에 **`.sum()`** 을 붙이면 컬럼별로 True(결측)의 개수를 세어 결측치가 몇 개인지 확인한다.
- `train_csv.describe()`는 컬럼별 개수·평균·최소·최대 등 요약 통계를 보여준다.

### x, y 분리 — count·casual·registered 세 개를 제거
```python
x = train_csv.drop(['casual', 'registered', 'count'], axis=1)   # (10886, 8)
y = train_csv['count']                                          # (10886,)
```
- 예측 대상인 **count**를 y로 뺀다.
- **casual, registered도 함께 제거**하는 이유:
  - count = casual + registered 관계라, 이 둘을 입력에 넣으면 정답을 그대로 알려주는 셈이 된다(정보 누수).
  - test.csv에는 casual·registered·count가 아예 없다(피처 8개뿐). 훈련 입력을 test와 같은 8개 컬럼으로 맞춰야 한다.
- 그래서 세 컬럼을 모두 빼서 x는 8컬럼이 된다 → `input_dim=8`.

### relu 활성화 함수 — 음수 예측 막기

예측값을 뽑아보면 **음수**가 섞여 나온다. `y = wx + b` 구조상 계산 결과가 음수가 될 수 있기 때문이다. 그러나 자전거 대여 수(count)는 음수가 될 수 없으므로, 음수가 나오지 않게 처리해야 한다. 이 처리는 **모델 구성 단계**에서 한다.

```python
model.add(Dense(100, activation='relu', input_dim=8))
model.add(Dense(100, activation='relu'))
...
model.add(Dense(1, activation='relu'))
```

- **relu**: `relu(x) = max(0, x)`. 즉 **0 이상은 원래 값 그대로, 0 미만(음수)은 0으로** 바꾼다. 그래프로 보면 양수 구간은 `y=x` 직선, 음수 구간은 전부 0으로 눌린다.
- `activation='relu'`를 각 층에 지정하면 **레이어를 통과할 때마다** 적용된다.
- **relu의 본래 목적은 성능(표현력) 향상**이다. 선형(직선) 계산만 쌓으면 아무리 깊어도 결국 하나의 직선과 같아지는데, relu 같은 **비선형** 함수를 층 사이에 끼워 넣어야 모델이 복잡한(곡선) 관계를 학습할 수 있다. 이 실습에서는 그 relu가 음수를 0으로 만드는 성질을 **대여 수의 음수 방지**에도 활용한 것이다.
- 출력층(`Dense(1)`)에 relu를 넣는 것은 통상적이지 않다(보통 회귀의 출력층에는 활성화 함수를 쓰지 않는다). 다만 출력층에 아무것도 안 넣으면 음수가 나오므로, 이 실습에서는 예외적으로 적용해 본 것이다.

## 6. 오늘 한 줄 요약

> 제출용 test 데이터는 행을 지울 수 없으므로 결측치를 **삭제(dropna)가 아닌 평균 채우기(fillna)** 로 처리하고, 예측값을 submission의 count에 채워 `to_csv`로 제출 파일을 만든다.
> 자전거 대여 예측에서는 정답을 구성하는 casual·registered를 count와 함께 제거하고(누수·test 부재), `y=wx+b`가 만드는 음수 예측을 막기 위해 **relu**(음수→0) 활성화 함수를 층마다 적용한다. relu의 본래 역할은 비선형성을 더해 모델 성능을 높이는 것이다.
