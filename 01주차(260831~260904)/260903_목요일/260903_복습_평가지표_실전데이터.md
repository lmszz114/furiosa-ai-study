## 0. 복기 — MSE와 loss 용어

### MSE (Mean Squared Error, 평균 제곱 오차)
(실제값 − 예측값)을 제곱해 전부 더한 뒤, 데이터 개수로 나눈 값.

$$ MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 $$

- yᵢ = 실제값, ŷᵢ = 예측값(= wx + b), n = 데이터 개수.

### loss = error = 오차 = cost
딥러닝에서 이 네 단어는 사실상 같은 의미로 통용된다. 모두 "모델의 예측이 정답에서 얼마나 벗어났는가"를 가리킨다.

### 평균을 쓰는 이유
오차를 단순히 합산만 하면 데이터 개수가 많을수록 값이 무조건 커져, 데이터 수가 다른 경우끼리 비교할 수 없다. 개수로 나눠 평균을 내면 "데이터 한 개당 평균 오차"가 되어, 데이터 양과 무관하게 하나의 대표값으로 비교할 수 있다.

---

## 1. 심화 — MSE의 한계와 RMSE

### MSE의 문제점
MSE는 오차를 **제곱**하기 때문에 값이 실제 오차보다 과장된다. 실제 오차가 100이면 MSE에서는 100² = 10000이 되어, 오차의 크기를 직관적으로 가늠하기 어렵다.

### RMSE (Root Mean Squared Error)
MSE에 루트(제곱근)를 씌워 제곱을 원위치시킨 값.

$$ RMSE = \sqrt{MSE} $$

- 제곱으로 부풀려진 값을 **원래 오차 단위로 되돌려** 해석을 쉽게 한다. 오차 100이 MSE 10000이 됐다면, RMSE는 다시 100 수준으로 돌아온다.

## 2. R² (결정계수) — loss를 보완하는 보조지표

### loss만으로는 부족한 이유
loss(mse/rmse)는 **상대적** 지표다. 두 모델의 loss가 1과 10이면 1이 낫다고 판단할 수 있지만(비교 가능), loss가 10 하나만 주어지면 그 자체로 좋은지 나쁜지 **절대적 판단이 불가능**하다.

### 모델 종류와 보조지표
- **회귀모델**: 수치를 예측한다. 표준화된 보조지표로 **R²(결정계수)** 를 쓴다.
- **분류모델**: 정해진 범주(n개) 중 맞는 것을 예측한다. 보조지표로 **accuracy(정확도)** 를 쓴다.

loss에 이런 보조지표를 함께 두어 모델을 평가한다.

### R²의 의미와 범위
R²는 "내 모델의 오차"를 "그냥 데이터의 평균값으로만 찍었을 때의 오차"와 비교한 값이다.

$$ R^2 = 1 - \frac{\text{모델의 오차}}{\text{평균값으로 찍었을 때의 오차}} $$

- **R² = 1**: 모델 오차가 0. 완벽.
- **R² = 0**: 모델이 평균값으로 찍는 수준.
- **R² < 0 (음수)**: 모델이 평균값으로 찍느니만 못한 상태. **최댓값은 1이지만 아래로는 열려 있어 음수가 나올 수 있다.**

음수 R²는 대부분 **모델이 아직 제대로 학습되지 않은 신호**다. epochs가 너무 적거나, 학습이 발산했거나, 예측이 뒤죽박죽일 때 나타난다.

### 판단의 최종 기준은 loss
R²·accuracy는 보조지표이며, 모델 판단의 기준은 항상 loss다. 예를 들어 loss가 낮은 모델이 R²가 다소 낮게 나오더라도, 판단은 loss가 낮은 쪽을 우선한다.

## 3. keras12_R2_RMSE_01_boston — R²·RMSE를 코드로 구현

R²와 RMSE는 **#4 평가·예측** 단계에서 계산한다.

### 평가 — evaluate에 x_test, y_test를 넣는 이유
```python
loss = model.evaluate(x_test, y_test)
```
- 평가는 훈련에 쓰지 않은 test 데이터로 한다.
- 예측값 ŷ = w·x + b 를 구하려면 입력 x가 필요하다 → **x_test**.
- loss = Σ(y − ŷ)² / n 을 구하려면 실제값 y가 필요하다 → **y_test**.

### 예측 — predict로 ŷ 생성
```python
y_predict = model.predict(x_test)
```
- x_test를 넣어 예측값(ŷ)을 만든다.

### R² 계산 — r2_score
```python
from sklearn.metrics import r2_score, mean_squared_error
r2 = r2_score(y_test, y_predict)
```
- `r2_score(실제값, 예측값)` 순서로 넣어 R²를 산출한다. R²의 내부 계산은 사이킷런이 처리한다.

### MSE·RMSE 계산
```python
mse = mean_squared_error(y_test, y_predict)

def RMSE(y_test, y_predict):
    return np.sqrt(mean_squared_error(y_test, y_predict))  # np.sqrt = 루트 씌우기
rmse = RMSE(y_test, y_predict)
```
- `mean_squared_error(실제값, 예측값)` 로 MSE를 구한다.
- RMSE는 별도 내장 함수가 없어 **MSE에 `np.sqrt`(제곱근)를 씌워** 직접 함수로 정의한다.

계산 순서: evaluate로 loss 확인 → predict로 ŷ 생성 → r2_score / mean_squared_error / RMSE로 지표 산출.

## 6. keras13_ddarung — pandas로 실전 데이터 다루기

숫자로 이뤄진 배열이 아니라 **csv 파일**을 다루므로 **pandas** 라이브러리를 사용한다.

### 폴더 구조
- `_data/ddarung/` 아래에 `train.csv`, `test.csv`, `submission.csv`를 둔다.
- 코드의 경로: `path = "./_data/ddarung/"`

### csv 읽기 — read_csv와 index_col
```python
train_csv = pd.read_csv(path + "train.csv", index_col=0)
```
- **`index_col=0`**: 첫 번째 컬럼(id)을 데이터가 아니라 **인덱스(행 번호)** 로 쓴다.
- id는 각 행을 구분하는 식별자일 뿐, 대여량 예측에 쓰이는 값이 아니므로 데이터에서 제외한다.
- 원본 train.csv는 11컬럼이지만, `index_col=0`으로 id를 인덱스 처리하면 **10컬럼**이 된다. (1459행)
- test.csv는 count 컬럼이 없어 **9컬럼**이다. (715행) — 예측 대상.
- submission.csv는 **1컬럼**(count)이다. (715행) — 제출 양식.

### 컬럼명은 데이터가 아니다
csv의 첫 줄(헤더)은 pandas가 자동으로 **컬럼명**으로 인식하며, 수치 연산 대상에서 제외된다.

실제 컬럼 구성:

| 컬럼명 | 의미 |
|---|---|
| hour | 시간 |
| hour_bef_temperature | 1시간 전 기온 |
| hour_bef_precipitation | 1시간 전 강수 여부 (비 안 옴 0 / 비 옴 1) |
| hour_bef_windspeed | 1시간 전 평균 풍속 |
| hour_bef_humidity | 1시간 전 습도 |
| hour_bef_visibility | 1시간 전 시정(가시거리) |
| hour_bef_ozone | 1시간 전 오존 |
| hour_bef_pm10 | 1시간 전 미세먼지(머리카락 굵기의 1/5~1/7 크기) |
| hour_bef_pm2.5 | 1시간 전 초미세먼지(머리카락 굵기의 1/20~1/30 크기) |
| count | 해당 시간의 따릉이 대여 수 (예측 대상 = y) |

*(`hour_bef_` 접두어는 해당 시각 기준 1시간 전 측정값을 뜻한다. 컬럼 의미는 대회 데이터 설명 기준.)*

### 구조 확인 함수
```python
print(train_csv.shape)      # 데이터 없이 (행, 열)만 확인
print(train_csv.columns)    # 컬럼명 목록
print(train_csv.info())     # 컬럼별 자료형과 결측치(non-null) 개수
```

### 결측치(non-null) 처리 — 삭제(dropna)
```python
train_csv = train_csv.dropna()   # 결측치가 있는 행을 삭제
```
- 결측치를 임의 값으로 유추하는 것이 부적절할 때 삭제를 택한다.
- 판단 기준: 소수의 이상치(예: 50대 10명의 평균 연봉에서 한 명만 100억)를 임의 유추하는 것은 왜곡을 부르므로 삭제가 낫다. 반대로 1000개 중 999개가 결측이면 삭제 시 데이터가 1개만 남으므로 삭제는 부적합하다.
- dropna 후 train_csv는 1328행이 된다.

### x와 y로 분리
예측 대상인 count가 y, 나머지 컬럼이 x가 된다.
```python
x = train_csv.drop(['count'], axis=1)   # count를 뺀 나머지 → x
y = train_csv['count']                  # count → y
```
- **`drop(['count'], axis=1)`**: `axis=1`은 열(컬럼) 방향 삭제를 뜻한다. count 컬럼을 제거해 x를 만든다. → x는 (1328, 9).
- `train_csv['count']`로 count만 뽑아 y로 쓴다. → y는 (1328,) 벡터.

### 분리·모델·평가
```python
x_train, x_test, y_train, y_test = train_test_split(
    x, y, random_state=888,
)

model = Sequential()
model.add(Dense(100, input_dim=9))   # 피처 9개
model.add(Dense(50))
model.add(Dense(50))
model.add(Dense(1))

model.compile(loss='mse', optimizer='adam')
model.fit(x_train, y_train, epochs=2000, batch_size=5)

y_predict = model.predict(x_test)

def RMSE(y_test, y_predict):
    return np.sqrt(mean_squared_error(y_test, y_predict))
rmse = RMSE(y_test, y_predict)
```
- 훈련은 `x_train, y_train`으로 하고, 평가는 훈련에 쓰지 않은 `x_test`로 예측해 RMSE를 구한다. 훈련에 쓴 데이터로 평가하면 이미 본 데이터를 채점하는 셈이 되어 성적이 실제보다 좋게 나온다.
- 대회 평가지표가 RMSE이므로, 로컬에서도 RMSE로 성능을 확인한다.

## 8. 오늘 한 줄 요약

> MSE는 제곱이라 오차가 과장되므로 루트를 씌운 **RMSE**로 해석을 쉽게 하고, loss만으로 절대 판단이 어려운 점을 **R²(회귀)·accuracy(분류)** 보조지표로 보완한다. R²는 최댓값 1이며 음수는 모델이 덜 학습된 신호다. 판단의 최종 기준은 loss.
> 실전 데이터(따릉이 csv)는 **pandas**로 읽어 `index_col`로 식별자를 빼고, `dropna`로 결측치를 처리한 뒤, `drop`으로 예측 대상(count)을 분리해 x/y를 만든다.
