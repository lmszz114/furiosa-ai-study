## 1. 코드 첫 줄부터 — TensorFlow와 Keras란?

`keras01` 맨 위 `import` 줄에서 이미 등장하는데 그냥 넘어간 개념들.

### TensorFlow란?
- 딥러닝 모델을 만들고 학습시키는 데 필요한 계산을 대신 해주는 **도구 상자(라이브러리)**. 구글이 만들었다.
- 딥러닝은 속을 보면 엄청난 양의 **곱셈·덧셈(행렬 연산)** 과, "오차를 줄이려면 가중치를 어느 방향으로 고쳐야 하나"를 계산하는 **미분** 덩어리다. 이걸 손으로 다 짜면 코드가 수백 줄. TensorFlow가 이걸 함수 몇 줄로 대신 처리해준다.
- 이름 뜻: **Tensor**(숫자 데이터 덩어리 = 다차원 배열) + **Flow**(그 데이터가 계산 과정을 따라 흐름). `np.array([1,2,3])` 같은 게 텐서의 기본 형태.

### 사실 오늘 친 건 대부분 "Keras"다
- **TensorFlow** = 무거운 계산을 담당하는 **엔진**.
- **Keras(케라스)** = 그 엔진을 쉽게 쓰라고 위에 얹은 **사용자 인터페이스**.
- 오늘 쓴 `Sequential`, `Dense`, `compile`, `fit` 이 전부 **Keras 문법**이다.
- 비유: TensorFlow가 자동차 엔진이면 Keras는 운전대·페달. 엔진 내부 몰라도 운전대(Keras)로 조작하면 된다.

## 2. 모든 코드의 공통 뼈대 — 4단계

`keras01~06`은 전부 똑같은 4단계 구조의 반복이다. 이게 앞으로 모든 모델 코드의 기본형.

```
1. 데이터        →  x(입력·문제), y(정답) 준비
2. 모델 구성      →  Sequential에 층(layer) 쌓기
3. 컴파일 · 훈련   →  loss·optimizer 정하고 fit()으로 학습
4. 평가 · 예측     →  evaluate()로 성적 확인, predict()로 새 값 예측
```

## 3. keras01 — 첫 모델: 노드 1개짜리 선형회귀

가장 단순한 형태. x와 y가 완전히 똑같아서(`[1,2,3]`) `y = 1·x + 0`이라는 딱 떨어지는 정답이 존재하는 데이터.

### ① 데이터
```python
x = np.array([1,2,3])
y = np.array([1,2,3])
```
- `x` = 입력값(문제), `y` = 정답(라벨). 모델은 x를 보고 y를 맞히는 규칙을 찾는다.

### ② 모델 구성
```python
model = Sequential()
model.add(Dense(1, input_dim=1))
```
- **Sequential**: 층을 위에서 아래로 순서대로 쌓는 모델 상자.
- **Dense(밀집층)**: 앞 층 노드와 다음 층 노드가 전부 연결된 가장 기본 층.
- **`Dense(1, input_dim=1)`**: 앞의 `1`은 **출력 노드 수**, `input_dim=1`은 **입력 개수(특성 수)**. `input_dim`은 데이터가 처음 들어오는 **첫 층에만** 써주면 된다.
- 용어: **노드(node)** = 계산 단위 하나 / **레이어(layer)** = 노드들의 묶음. 노드·레이어를 늘리는 게 곧 딥러닝으로 가는 길.

### ③ 학습의 목표 — `y = wx + b` (여기서 핵심 개념 3개)
`keras01` 주석의 "최소의 오차, 최적의 가중치 찾기"가 이 부분이다.

**(1) 왜 딥러닝은 1차 함수(직선)로 시작하나**
- 노드 하나가 하는 일 = 딱 `입력 × 가중치 + 편향`, 즉 `w·x + b` 계산 하나. 이게 신경망의 **최소 부품**이다.
- 1차(직선)는 가장 단순한 관계(비례 + 위치 조정)라 계산이 가볍고, 이 단순한 부품을 **여러 개 조합하면 복잡한 것도 표현** 가능하기 때문. (레고 기본 블록 하나는 단순하지만 많이 쌓으면 복잡한 걸 만드는 것과 같다.)

**(2) 왜 수학의 `a`를 `w`로 바꿔 쓰나**
- 학교 1차 함수는 `y = ax + b`. 딥러닝은 `y = wx + b`. 글자만 바꾼 게 아니라 **보는 관점이 다르다.**
- 수학의 `a` = **기울기(slope)**, 직선이 얼마나 가파른가 하는 **모양** 관점.
- 딥러닝의 `w` = **weight(가중치)**, 이 입력을 결과에 **얼마나 비중 있게 반영할지** 하는 **중요도** 관점.
- 입력이 여러 개일 때 진가가 드러난다:
  ```
  y = w1·x1 + w2·x2 + w3·x3 + b
  ```
  각 입력마다 자기 가중치가 붙어서, w가 크면 "크게 반영", 0에 가까우면 "거의 무시". 즉 w는 **각 입력의 중요도 손잡이**. 이걸 "기울기"라 부르면 의미가 안 살아서 필드에선 **가중치**라 부른다. (입력 1개인 오늘 코드에선 우연히 w가 기울기와 같은 값이 됨.)

**(3) 가중치 w와 편향 b가 실제로 뭔지**
- **가중치(weight, w)**: 입력에 곱해지는 숫자 = 그 입력의 **영향력 세기**. 오디오 믹서의 볼륨 손잡이. **학습 = 이 w를 계속 미세 조정해 오차를 줄이는 것.**
- **편향(bias, b)**: 결과에 더해주는 값 = 직선을 위아래로 **평행 이동**. 입력이 0이어도 결과가 0이 아닐 수 있게 해서 모델을 유연하게 만든다. 저울의 **영점 조절**에 해당.
- 합치면:
  ```
  결과 = (입력 × 가중치) + 편향
   y   =   ( x  ·   w )  +   b
          └ 얼마나 중요? ┘  └ 기본 위치 ┘
  ```

### ④ 컴파일 — loss와 optimizer
```python
model.compile(loss='mse', optimizer='adam')
```
- **loss(손실 함수)**: 예측이 정답에서 얼마나 벗어났는지 재는 자. **작을수록 잘 맞힌 것.**
  - **mse** = 평균 제곱 오차. `(예측값 − 실제값)²`의 평균. 제곱하는 이유는 부호(+/−)를 없애고 크게 틀린 것에 더 큰 벌점을 주려고.
- **optimizer(최적화기)**: loss를 줄이는 방향으로 w, b를 실제로 조금씩 고치는 담당.
  - **adam** = 무난하게 잘 쓰이는 표준 옵티마이저. 일단은 "적당히 알아서 잘 조절해주는 기본값"으로 이해하고 넘어가면 됨.

### ⑤ 훈련 — epochs
```python
model.fit(x, y, epochs=8000)
```
- **fit()**: 실제로 학습을 돌리는 명령.
- **epochs**: 준비한 데이터 전체를 **몇 번 반복해서 볼지**. 8000이면 같은 데이터를 8000번 보며 w, b를 다듬는다. 많이 볼수록 오차는 대체로 줄지만 무한정 좋아지진 않는다.

### ⑥ 예측 — predict
```python
result = model.predict(np.array([4]))
```
- 학습으로 찾은 w, b로 **새 입력의 답을 내놓는다.** 1,2,3으로 배웠으니 4를 넣으면 4에 가까운 값이 나와야 정상.
- (참고: `tf.__version__` 출력은 설치가 제대로 됐는지 버전 확인용.)

## 4. keras02 — 데이터 늘리고 성적표(evaluate) 추가

데이터를 1~6으로 늘리고, 새로 **evaluate**가 등장.
```python
loss = model.evaluate(x, y)
```
- **evaluate**: 학습 끝난 모델의 **성적표**. 데이터를 넣어보고 loss(점수)만 돌려준다.
- **predict와 차이**: `predict`는 "실제로 값을 예측", `evaluate`는 "얼마나 잘 맞히는 모델인지 점수만 확인".

## 5. keras03 — 노이즈 데이터 등장 (중요한 전환점)

```python
x = np.array([1,2,3,4,5])
y = np.array([1,2,4,3,5])   # 일부러 삐뚤빼뚤
```
- 이제 **모든 점을 정확히 지나는 직선은 없다.** 그래서 loss가 0까지 안 떨어진다.
- 현실 데이터는 원래 이렇게 노이즈가 있고, 모델은 "완벽히 맞히기"가 아니라 **"전체적으로 가장 덜 틀리는 선"** 을 찾는다. 이 감을 잡는 게 이 단계의 핵심.

## 6. keras04~05 — 노드·레이어를 나눠 딥러닝으로

직선 하나(노드 1개)로는 삐뚤빼뚤한 데이터를 잘 못 따라간다. 그래서 **층을 여러 개 쌓고 각 층에 노드를 여러 개** 둔다. **이게 오늘 배운 "단일 → 딥러닝"의 핵심.**

```python
model.add(Dense(8, input_dim=1))  # 첫 층: 입력 개수 지정
model.add(Dense(8))               # 이후 층: 앞 층 출력이 자동 입력
model.add(Dense(8))
model.add(Dense(1))               # 마지막: 결과 1개 출력
```
- 층을 이어 쌓으면 앞 층의 출력이 다음 층 입력으로 **자동 전달**되므로, 두 번째 층부터는 `input_dim`을 안 써도 된다.
- 노드·레이어를 늘리면 모델이 표현할 수 있는 형태가 더 복잡해져서, 노이즈 낀 데이터도 더 유연하게 따라간다.

## 7. keras06 — batch_size로 훈련 방식 조절

```python
model.fit(x, y, epochs=5000, batch_size=1)
```
- **batch_size**: 한 번 w를 고칠 때 데이터를 **몇 개씩 묶어서 볼지.**
- `batch_size=1`이면 데이터 1개 볼 때마다 가중치를 한 번씩 갱신 → 데이터 6개면 한 epoch에 6번 갱신.
- 지정 안 하면 기본값이라 데이터 6개가 통째로 한 덩어리 → 한 epoch에 1번만 갱신.
- 즉 batch_size를 작게 할수록 **한 epoch 안에서 가중치를 더 자주 손본다.**

## 8. 전체 그림 한 장

```
[데이터 x] ──▶ 노드: (x · w) + b ──▶ [예측값 y]
                      │
                      ▼
              정답과 비교 → 오차(loss, mse로 측정)
                      │
                      ▼
        optimizer(adam)가 오차 줄이는 방향으로
              w, b를 조금 수정  ← 이걸 epochs 만큼 반복
```
- **TensorFlow / Keras**: 이 그림 전체를 자동으로 돌려주는 도구(엔진 + 운전대).
- **`wx+b`**: 노드 하나의 기본 계산 / **w**: 입력의 중요도 손잡이(학습의 핵심 대상) / **b**: 기본 위치 손잡이.
- **loss → optimizer → epochs**: 오차를 재고 → 손잡이를 고치고 → 반복하는 학습 사이클.
