## 0. 활성화 함수란 (왜 필요한가)

**활성화 함수는 뉴런(노드)의 출력값을 결정하는 함수**다. 입력에 가중치를 곱해 더한 값을 그대로 내보내지 않고, 이 함수를 한 번 거쳐 내보낸다.

**가장 중요한 역할은 "비선형성(non-linearity)"을 주는 것**이다. 활성화 함수가 없으면 아무리 층을 깊게 쌓아도 **선형 변환(직선)의 반복**일 뿐이라, 결국 하나의 선형식과 똑같아진다(층을 쌓는 의미가 없다). 활성화 함수가 중간에 곡선(비선형)을 넣어줘야 신경망이 **복잡한 패턴**을 학습할 수 있다.

함수마다 모양·출력 범위·장단점이 달라, 상황에 맞게 고른다. 오늘은 대표적인 8개를 직접 그려 비교한다.

### 공통 코드 패턴

8개 모두 같은 틀이다: **numpy로 수식을 구현 → x축 값을 만들고 → 함수에 넣어 → matplotlib로 그래프**.

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.arange(-5, 5, 0.1)      # -5부터 5까지 0.1 간격 (100개 점)
# 함수 = lambda x : <수식>      # 활성화 함수를 직접 구현
y = 함수(x)

plt.plot(x, y)                 # x-y 그래프
plt.grid()                     # 격자
plt.show()
```

- **`np.arange(-5, 5, 0.1)`**: 그래프를 그릴 x축 점들(−5 ~ 5, 촘촘히 100개).
- **`lambda x : 수식`**: 각 활성화 함수를 한 줄짜리 함수로 정의(지난 시간 배운 lambda).

## 1. Sigmoid — `1 / (1 + e^(-x))`

```python
sigmoid = lambda x : 1 / (1 + np.exp(-x))
```
- **출력 범위**: 0 ~ 1 (S자 곡선). 입력이 아주 크면 1, 아주 작으면 0에 수렴.
- **용도**: 결과를 **확률(0~1)** 로 보고 싶을 때. **이진 분류의 출력층**에 쓴다.
- **단점**:
  - **기울기 소실(gradient vanishing)**: 양 끝(아주 크거나 작은 입력)에서 기울기가 0에 가까워, 깊은 신경망에서 학습이 거의 안 되는 문제.
  - 출력이 0 중심이 아니다(항상 양수) → 학습 효율이 떨어질 수 있음.

## 2. Tanh — 하이퍼볼릭 탄젠트

```python
y = np.tanh(x)          # numpy 내장 함수
```
- **출력 범위**: −1 ~ 1 (S자 곡선). Sigmoid와 모양은 같지만 **0 중심**이다.
- **Sigmoid보다 나은 점**: 출력이 0을 중심으로 음수·양수에 걸쳐 있어 학습이 조금 더 안정적이다.
- **단점**: 여전히 양 끝에서 **기울기 소실**이 일어난다.

## 3. ReLU — `max(0, x)`

```python
relu = lambda x : np.maximum(0, x)
```
- **모양**: 음수는 전부 0, 양수는 그대로 통과(꺾은선).
- **가장 널리 쓰이는 활성화 함수.** 계산이 매우 간단하고, 양수 구간은 기울기가 1이라 **기울기 소실 문제를 크게 완화**한다.
- **단점 — Dying ReLU**: 입력이 음수면 출력도 기울기도 0이라, 어떤 뉴런이 계속 음수만 받으면 **영영 0만 내보내며 죽어버리는** 문제가 생긴다. (아래 4~8번은 대부분 이 문제를 개선하려는 변형들)

## 4. SiLU (Swish) — `x · sigmoid(x)`

```python
# 2017년 구글 발표, Sigmoid Linear Unit (= Swish)
silu = lambda x : x * (1 / (1 + np.exp(-x)))
```
- **x에 sigmoid를 곱한** 함수(2017년 구글). ReLU처럼 양수는 거의 그대로 통과하되, **음수 쪽이 0으로 딱 꺾이지 않고 부드럽게** 내려간다(살짝 음수도 통과).
- ReLU의 "딱딱한 꺾임"을 부드럽게 만들어, 깊은 모델에서 **ReLU보다 성능이 좋은 경우가 많다.**

## 5. Mish — `x · tanh(ln(1 + e^x))`

```python
mish = lambda x : x * np.tanh(np.log(1 + np.exp(x)))
```
- SiLU와 비슷하게 **부드러운 곡선**을 그리는 활성화 함수. 음수 쪽도 완전히 0이 아니라 약간 살아 있다.
- SiLU/Mish처럼 부드러운 함수들은 기울기 흐름이 매끄러워 **깊은 신경망에서 좋은 성능**을 내는 경향이 있다. (`ln(1+e^x)`는 softplus라는 함수다.)

## 6. ELU — Exponential Linear Unit

```python
alpha = 1
elu = lambda x, alpha : (x>0)*x + (x<0) * (alpha*(np.exp(x)-1))
```
- **양수(x>0)는 그대로**, **음수(x<0)는 지수 곡선**(`α(e^x−1)`)으로 **부드럽게 음의 값**까지 내려간다.
- **ReLU의 Dying 문제 완화**: 음수에서도 0이 아닌 값을 내보내 뉴런이 죽지 않는다. 출력이 음수까지 갈 수 있어 **0 중심에 가깝다**(학습에 유리).
- `alpha`는 음수 구간의 크기를 조절하는 값.

## 7. SELU — Scaled ELU

```python
alpha = 1.6732632423543772      # 논문이 제안한 고정 상수
lmbda = 1.0507009873554805
selu = lambda x, alpha, lmbda : lmbda * ((x>0)*x + (x<=0)*(alpha*(np.exp(x)-1)))
```
- **ELU에 고정된 배율(λ)을 곱한** 함수. `alpha`·`lmbda`는 논문에서 수학적으로 정한 **고정 상수**다(임의로 바꾸지 않음).
- **자기 정규화(self-normalizing)**: 특정 조건(이 상수 + 알맞은 초기화)에서 층을 통과한 출력의 평균·분산이 **자동으로 일정하게 유지**되어, 별도 정규화 없이도 깊은 망이 안정적으로 학습되도록 설계됐다.

## 8. Leaky ReLU — `x>0 : x,  x≤0 : αx`

```python
alpha = 0.01
def leaky_relu(x):
    return np.where(x > 0, x, alpha*x)    # 양수면 x, 음수면 0.01*x
```
- **ReLU의 Dying 문제를 직접 해결**한 버전. 음수 구간을 0으로 죽이지 않고, **아주 작은 기울기(`α`, 보통 0.01)** 로 **살짝 음수를 흘려보낸다**("leaky" = 새는).
- 음수에서도 기울기가 0이 아니라서(0.01), 뉴런이 죽지 않고 계속 학습에 참여한다.

## 9. 비교 정리 & 코드 트릭

### 활성화 함수 비교

| 함수 | 출력 범위 | 특징 | 음수 처리 |
|---|---|---|---|
| **Sigmoid** | 0 ~ 1 | 확률 출력, 이진분류 출력층 | — (기울기 소실) |
| **Tanh** | −1 ~ 1 | 0 중심, Sigmoid 개선 | — (기울기 소실) |
| **ReLU** | 0 ~ ∞ | 가장 많이 씀, 간단·빠름 | 0으로 죽임 (Dying) |
| **SiLU(Swish)** | 약 −0.3 ~ ∞ | 부드러운 ReLU, 성능↑ | 부드럽게 살짝 통과 |
| **Mish** | 약 −0.3 ~ ∞ | 부드러움, 성능↑ | 부드럽게 살짝 통과 |
| **ELU** | −α ~ ∞ | 음수 부드럽게, 0중심 근접 | 지수 곡선으로 통과 |
| **SELU** | 스케일된 ELU | 자기 정규화(고정 상수) | 지수 곡선 통과 |
| **Leaky ReLU** | −∞ ~ ∞ | Dying ReLU 해결 | 작은 기울기(αx)로 통과 |

- **큰 흐름**: Sigmoid·Tanh(기울기 소실) → **ReLU**(기본값, 간단하지만 Dying) → 그 단점을 고친 변형들(**Leaky ReLU·ELU·SELU**)과 더 부드러운 **SiLU·Mish**. 실무에선 **ReLU를 기본**으로 쓰고, 성능이 필요하면 SiLU/Mish 등을 시도한다.

### 코드에서 쓰인 numpy 트릭

- **`np.maximum(0, x)`**: 0과 x 중 큰 값 → ReLU 구현.
- **`np.where(조건, A, B)`**: 조건이 참인 자리는 A, 거짓인 자리는 B → Leaky ReLU처럼 "경우 나누기"에 쓴다.
- **`(x>0)*x`**: 불린 배열(True=1, False=0)에 x를 곱해 **조건을 만족하는 부분만** 남긴다. `(x>0)*x + (x<0)*(…)`로 양수·음수 구간을 나눠 더하는 방식(ELU·SELU).
- **`np.exp(x)`**(지수), **`np.tanh(x)`**, **`np.log(x)`**(로그): 수식을 그대로 코드로 옮길 때 쓰는 numpy 수학 함수들.

## 한 줄 요약

> **활성화 함수**는 뉴런 출력에 **비선형성**을 줘서 신경망이 복잡한 패턴을 배우게 하는 핵심 부품이다. **Sigmoid**(0~1, 이진분류 출력)·**Tanh**(−1~1, 0중심)는 양 끝에서 **기울기 소실**이 있고, **ReLU**(max(0,x))는 간단·빠르지만 음수 입력이 뉴런을 죽이는 **Dying ReLU** 문제가 있다. 이를 고친 게 **Leaky ReLU**(음수도 작은 기울기 αx), **ELU**(음수 지수곡선·0중심 근접), **SELU**(고정 상수로 자기 정규화)이고, **SiLU(Swish, x·sigmoid)·Mish**는 ReLU를 더 부드럽게 만들어 깊은 모델에서 성능이 좋은 변형이다. 코드에선 각 수식을 numpy(`np.maximum`·`np.where`·`(x>0)*x`·`np.exp`·`np.tanh`)로 구현해 matplotlib로 그려 모양을 비교했다.
