## 1. keras73_15~18 — 전이학습(동결)을 실제 이미지 데이터에 적용

어제 cifar에 쓴 "VGG16 특징 추출기 동결 + 내 분류기" 구조를, 전에 다루던 실제 이미지 데이터(말/사람, 가위바위보, 남/여, 고양이/개)에 그대로 적용한다. 데이터 로드는 `ImageDataGenerator`로 하던 방식 그대로고, 모델만 VGG16 전이학습으로 바뀐다.

```python
# keras73_vgg16_15_man_horse
path = './_data/image/horse_human/'
train_datagen = ImageDataGenerator(rescale=1./255)   # 0~255 → 0~1

xy = train_datagen.flow_from_directory(
    path, target_size=(200,200), batch_size=10000,
    class_mode='binary', color_mode='rgb', shuffle=True,
)
x = xy[0][0]; y = xy[0][1]
print(x.shape, y.shape)   # (1027, 200, 200, 3) (1027,)

x_train, x_test, y_train, y_test = train_test_split(
    x, y, train_size=0.8, random_state=1024, stratify=y)

#2. 모델 — VGG16 전이학습
vgg16 = VGG16(weights='imagenet', include_top=False, input_shape=(200, 200, 3))
vgg16.trainable = False            # 특징 추출기 동결
model = Sequential()
model.add(vgg16)
model.add(Flatten())
model.add(Dense(100))
model.add(Dense(100))
model.add(Dense(1, activation='sigmoid'))   # 이진분류

model.compile(loss="binary_crossentropy", optimizer="adam", metrics=['acc'])
```

- **`flow_from_directory`로 폴더 구조에서 이미지와 라벨을 한 번에 읽는다.** 하위 폴더 이름이 곧 클래스다. `batch_size`를 데이터 수보다 크게(10000) 줘서 `xy[0]`에 전체가 한 덩어리로 담기고, 거기서 `x = xy[0][0]`(이미지), `y = xy[0][1]`(라벨)를 꺼낸다. `rescale=1./255`로 픽셀을 0~1로 맞춘다.
- **출력층과 손실은 클래스 수에 맞춘다.** 말/사람 같은 2종은 `Dense(1, sigmoid)` + `binary_crossentropy`, 가위바위보 같은 3종 이상은 softmax + categorical 계열을 쓴다. VGG16 전이학습 부분(동결 + 내 분류기)은 데이터가 바뀌어도 동일하고, `input_shape`만 이미지 크기(여기선 200×200×3)에 맞춘다.
- **결과(동결 O)**: man_horse에서 acc 1.0. 사전학습 특징이 비교적 단순한 이진 구분(말/사람)에 잘 맞아 높은 정확도가 나왔다. rps·man_woman·cat_dog도 같은 구조로 데이터만 바꿔 돌린 실습이다.

## 2. keras74_1~4 — 가중치 개수로 동결 확인 · 부분 동결

### 2-1. 동결하면 trainable_weights 개수가 준다 (74_1)

```python
vgg16 = VGG16(weights="imagenet", include_top=False, input_shape=(32, 32, 3))
vgg16.trainable = False

model = Sequential()
model.add(vgg16)
model.add(Flatten())
model.add(Dense(100))
model.add(Dense(10, activation='softmax'))

print(len(model.weights))             # 30
print(len(model.trainable_weights))   # 4
```

**가중치 개수로 동결 상태를 확인한다.** 층 하나당 가중치는 kernel·bias 2개다(어제 정리). VGG16(include_top=False)은 합성곱 층이 13개라 13×2 = 26개, 거기에 내가 붙인 Dense 2개 ×2 = 4개를 더해 전체 `model.weights`는 **30개**다. VGG16을 동결하면 그 26개는 학습 대상에서 빠지고, 내 Dense의 **4개만** `trainable_weights`에 남는다. 즉 전이학습의 "특징 추출기는 그대로, 내 분류기만 학습"이 숫자로 30 → 4로 나타난다.

### 2-2. 레이어별 동결 상태를 표로 확인 (74_2)

```python
import pandas as pd
pd.set_option('max_colwidth', None)
layers = [(type(layer).__name__, layer.name, layer.trainable) for layer in model.layers]
results = pd.DataFrame(layers, columns=['Layer Type', 'Layer Name', 'Layer Trainable'])
print(results)
#    Layer Type Layer Name  Layer Trainable
# 0  Functional      vgg16            False     ← 동결됨
# 1     Flatten    flatten             True
# 2       Dense      dense             True
# 3       Dense    dense_1             True
```

**`model.layers`를 돌며 각 층의 종류·이름·학습 여부를 표로 만든다.** `layer.trainable`이 그 층의 동결 여부다. 동결한 vgg16만 False, 나머지는 True로 나온다. 어느 층이 학습되고 안 되는지 한눈에 점검하는 방법이다. (`model.layers`에서 vgg16은 그 자체로 하나의 묶음 층(Functional)으로 잡힌다.)

### 2-3. 내 모델의 특정 층만 부분 동결 (74_3)

```python
model.add(vgg16); model.add(Flatten())
model.add(Dense(100)); model.add(Dense(90)); model.add(Dense(80))
model.add(Dense(70)); model.add(Dense(10, activation='softmax'))

model.layers[2].trainable = False    # 3번째 층(첫 Dense)만 동결
```

**`model.layers[인덱스].trainable = False`로 특정 층 하나만 골라 동결한다.** 전체(`vgg16.trainable`)가 아니라 원하는 층만 선택적으로 얼리는 것이 **부분 동결**이다. 위에서는 `layers[2]`(Flatten 다음 첫 Dense)만 False가 되고 나머지 Dense는 학습된다. 표로 확인하면 해당 층만 Layer Trainable이 False로 바뀐다.

### 2-4. 사전학습 모델 "내부" 층을 부분 동결 (74_4)

```python
vgg16 = VGG16(weights="imagenet", include_top=False, input_shape=(32, 32, 3))
# vgg16.trainable = False          # 전체 동결 대신
vgg16.layers[11].trainable = False # VGG16 내부의 11번째 층만 동결
```

**`vgg16.layers[인덱스].trainable`로 사전학습 모델 안쪽 층 단위까지 동결을 조절한다.** 2-3이 내가 만든 Sequential의 층을 고르는 것이라면, 여기서는 가져온 VGG16 **내부의 개별 층**을 지정해 동결한다. 전체를 얼리거나(`vgg16.trainable=False`) 다 푸는 것 외에, "앞쪽 일반적 특징 층은 얼리고 뒤쪽 층만 다시 학습" 같은 세밀한 조절이 가능하다는 것을 보여준다. (파일 하단 주석의 표는 이전 파일(74_3)에서 복사된 것이라 이 코드의 실제 출력과는 일치하지 않는다.)

## 3. keras75_All_TransferLearning — 여러 사전학습 모델을 for문으로 비교

`keras.applications`에는 VGG 외에도 많은 사전학습 모델이 있다. 이들을 리스트에 담아 for문으로 돌리며 가중치 구조를 비교한다.

```python
import warnings
warnings.filterwarnings("ignore")   # 경고 메시지 숨김(버전 안내 등 분석에 불필요한 출력 정리)

from keras.applications import VGG16, VGG19, ResNet50, ResNet101, DenseNet201, \
    InceptionV3, MobileNet, MobileNetV2, NASNetMobile, EfficientNetB0, Xception
# ... (ResNet/DenseNet/MobileNet/NASNet/EfficientNet 계열 다수)

model_list = [VGG16(), VGG19(), ResNet50(), ResNet50V2(), ResNet101(), ...]

for model in model_list:
    model.trainable = False
    print("모델명: ", model.name)
    print("전체 가중치 갯수: ", len(model.weights))
    print("전체 훈련가능 가중치 갯수: ", len(model.trainable_weights))
```

- **`keras.applications`는 ImageNet으로 미리 학습된 유명 모델들을 바로 불러 쓰게 해준다.** VGG16/19, ResNet(50·101·152와 V2), DenseNet(121·169·201), Inception, MobileNet(V2·V3), NASNet, EfficientNet(B0~B2), Xception 등 종류가 많다. 모델마다 깊이·구조·파라미터 규모가 달라 특징 추출 능력과 속도가 다르다.
- **여러 모델을 리스트에 담아 for문으로 한 번에 처리한다.** 모델마다 똑같은 코드(동결 → 가중치 개수 출력)를 반복 작성하지 않고, `model_list`를 순회하며 동일 작업을 적용한다. 모델별로 `model.name`, 전체/훈련가능 가중치 수를 뽑아 구조 규모를 비교한다.
- **`model.trainable = False`로 동결하면 어느 모델이든 `trainable_weights`가 0에 가까워진다.** 동결은 특정 모델만의 기능이 아니라 공통 속성임을 여러 모델에서 확인한다.
- **`warnings.filterwarnings("ignore")`** 는 실행 중 뜨는 경고 메시지를 숨겨 출력을 깔끔하게 한다. 모든 경고를 영구히 없애는 것이 아니라 이 실행의 화면 출력만 정리하는 용도다.

## 4. keras76_1~6 — 여러 모델을 for문으로 실제 데이터에 학습·비교

keras75가 "가중치 개수 비교"였다면, keras76은 여러 사전학습 모델을 **실제 데이터로 학습시켜 성능(acc)을 비교**한다. cifar10·cifar100·man_horse·rps·man_woman·cat_dog 각각에 대해 같은 틀로 돌린다.

```python
model_list = [VGG19(include_top=False, input_shape=(32, 32, 3)),
              ResNet50(include_top=False, input_shape=(32, 32, 3)),
              ResNet101(include_top=False, input_shape=(32, 32, 3)),
              DenseNet201(include_top=False, input_shape=(32, 32, 3)),
              MobileNetV2(include_top=False, input_shape=(32, 32, 3))]

(x_train, y_train), (x_test, y_test) = cifar10.load_data()
x_train = x_train/255.; x_test = x_test/255.

for model_i in model_list:
    model_i.trainable = False            # 특징 추출기 동결
    model = Sequential()
    model.add(model_i)
    model.add(GlobalAveragePooling2D())  # Flatten 대신 특성맵 평균으로 압축
    model.add(Dense(32))
    model.add(Dense(16))
    model.add(Dense(10, activation='softmax'))

    model.compile(loss="sparse_categorical_crossentropy", optimizer="adam", metrics=["acc"])
    model.fit(x_train, y_train, epochs=50, batch_size=32, verbose=0, validation_split=0.2)
    loss = model.evaluate(x_test, y_test, verbose=0)
    print("모델명: ", model_i.name, "loss: ", loss[0], "acc", loss[1])
```

- **사전학습 모델을 리스트에 담아, 각각 동결 → 내 분류기 붙이기 → 학습 → 평가를 for문으로 반복한다.** 모델만 바뀔 뿐 뒤 분류기와 학습 설정은 동일하게 두고 성능을 공정하게 비교한다. 여기서는 `include_top=False`, `input_shape`를 데이터(32×32×3)에 맞춰 불러온다.
- **`GlobalAveragePooling2D`로 특성맵을 2D로 바꾼다.** Flatten이 특성맵을 전부 펴는 것과 달리, GAP2D는 각 채널의 평균 하나로 압축한다. 펼친 크기가 커 파라미터가 폭증하는 것을 막아 여러 모델을 가볍게 비교하기에 적합하다.
- **`model.fit(..., verbose=0)`** 으로 학습 로그를 숨긴다. 여러 모델을 연달아 돌리므로 진행 로그를 끄고 최종 결과(모델명·loss·acc)만 출력한다.

**결과 — 데이터·모델에 따라 성능이 크게 갈린다(cifar10, 실측).**

| 모델 | acc |
|---|---|
| densenet201 | 0.586 |
| vgg19 | 0.536 |
| resnet50 | 0.327 |
| mobilenetv2 | 0.305 |
| resnet101 | 0.246 |
| efficientnetb0 | 0.100 (사실상 실패) |

- 같은 데이터·같은 분류기인데도 사전학습 모델에 따라 acc가 0.10~0.59로 크게 갈린다. **"유명하고 큰 모델이 항상 더 좋은 것은 아니다"** — 데이터 특성과 모델 구조의 궁합이 성능을 좌우한다. (추측: cifar10은 32×32로 작은 이미지인데, EfficientNet·ResNet101 같은 큰 모델은 큰 이미지에 맞춰 설계돼 작은 이미지·짧은 학습에서는 특징을 제대로 못 살려 낮게 나온 것으로 보인다.)
- 이 실습의 요지는 **여러 모델을 for문으로 한 번에 비교해, 내 데이터에 맞는 모델을 실험으로 고르는 것**이다. cifar100·man_horse·rps·man_woman·cat_dog도 같은 틀에 데이터만 바꿔 돌렸다.

## 5. 오늘 한 줄 요약

> **전이학습 동결 적용** — VGG16(include_top=False, 동결) + 내 분류기 구조를 실제 이미지 데이터(말/사람 등)에 그대로 쓴다. 데이터는 `flow_from_directory`로 읽고, 출력층·손실만 클래스 수에 맞춘다.
> **동결 확인·부분 동결** — 층당 가중치는 2개(kernel·bias)라, VGG16 동결 시 `model.weights` 30개 중 내 Dense `trainable_weights` 4개만 남는다. `layer.trainable`을 표로 확인하고, `model.layers[i].trainable=False`(내 층) 또는 `vgg16.layers[i].trainable=False`(사전학습 내부 층)로 **특정 층만 골라 부분 동결**할 수 있다.
> **여러 모델 비교** — `keras.applications`의 다양한 사전학습 모델(VGG·ResNet·DenseNet·Inception·MobileNet·EfficientNet 등)을 리스트에 담아 for문으로 돌린다. 가중치 개수 비교(keras75)에서 실제 학습·성능 비교(keras76)로 확장하며, `GlobalAveragePooling2D`·`verbose=0`·`warnings.filterwarnings("ignore")`로 간결하게 돌린다. 큰 모델이 늘 좋은 것은 아니고 데이터와의 궁합이 성능을 가른다.
